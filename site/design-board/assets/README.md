# Assets — folder map

Each line lives in its own folder. Each Culture Run drop has garment + print together.

```
assets/
  references/                 original 龍 samples
  men-kanji/
    belts/  apparel/  accessories/
    marks/                    kanji cards + patches (factory)
  women-floral/
    sakura/                   pink SKUs
    lavender/                 lilac SKUs
    marks/                    flower sheets
  culture-run/
    <drop>/
      singlet.png | tank.png | tee.png
      print.png               locked composite (texture + marks)
      print-bg.png            texture only — no kanji, no logo, no type
    _layers/                  transparent 走 / 山 / hex C / CN marks
    _archive-v1/              flat charcoal pieces (superseded)
```
