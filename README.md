## Browse on your domain

After `git pull`, run once:

```bash
bash scripts/build-site.sh
```

Point your web server at the **`site/`** folder (not the repo root) and open your domain. The hub includes logos, kanji designs, docs, and the design board.

→ Deploy notes: [`docs/deploy.md`](docs/deploy.md)

## Design board (local dev)

```bash
cd design-board && npm install && npm run dev
```

Open **http://localhost:5177** — tabs: Brand · Men Kanji · Women Floral · Culture Run · Pace · Forge · Padel · Production marks.
