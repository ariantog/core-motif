# Corenation Culture Run — Shirts & Tanks

**Brand:** Corenation Active  
**Line:** Culture Run — lightweight running tees, tanks, singlets  
**Accounts:** @corenationactive (women + brand) · @corenationmen (men's Wave / Summit)  
**Positioning:** Adidas running-club energy. Graphic posters on fast fabrics. Not a lifting patch. Not a souvenir tee.

---

## What "Culture" means

One cultural **graphic story** per shirt. Stories we already train with:

| Graphic | Story | Gender home | Kanji? |
|---------|--------|-------------|--------|
| **Wave** | Japanese current / Hokusai simplified — motion | Men | **走** (run) only, integrated in the wave |
| **Summit** | Mountain / volcano line — climb the session | Men / unisex | Optional small 山 or 峰 at hem, not a chest patch |
| **Bloom Path** | Sakura along a path — women's long run | Women | No |
| **Dusk** | Lavender field + dusk sky — easy run / recovery jog | Women | No |
| **Home Soil** | Indonesian dawn ridge (Bromo / Arjuno silhouette, abstract) | Unisex | No |

This is **not** batik costume, not a temple tourist print, not a collage of torii + wayang + flags.

## Garment rules

- Silhouettes: short-sleeve run tee, race tank, singlet. Lightweight, mesh allowed, split hem OK.
- **Back = poster.** Front = hex C + `CORENATION` or `CULTURE RUN` small.
- One graphic. No second hero on the sleeve.
- Men Wave/Summit: charcoal, ink, cream, red. Olive only as 5mm binding.
- Women Bloom/Dusk: sakura pink or lilac grounds — same floral palettes as the women's line, **graphic scale** (back print), not a tiny belt blossom.
- Singlet: graphic must survive narrow shoulders — test on size S.

---

## Graphic specs

### Wave (走)

- Simplified wave (3–5 crests), cream or red on charcoal.
- 走 sits in the trough or as a large mark breaking the crest — still one idea.
- Phrase (optional, back hem): `前へ走れ` or `CULTURE RUN`.
- Do not use 龍 on this shirt (dragon stays on lifting shorts).

### Summit

- One ridge line + one peak. Cream on ink, or ink on cream.
- Feels like a route, not a postcard. No sun-with-face, no snow-cap cartoon.

### Bloom Path

- A path of 5–9 sakura, larger at hem, smaller toward the shoulders (depth).
- Pink or cream tank. Deep rose blossoms.

### Dusk

- Low lavender spikes along the back hem, dusk sky fade **subtle** (print, not gradient-luxury).
- Lilac or charcoal women's tee.

### Home Soil

- Abstract ridge (Javanese volcanic profile), cream on ink.
- Small `CORENATION` / `SURABAYA` or `HOME SOIL` — not a flag.
- Use this when we need the brand to look Indonesian, not only Japanese-coded.
