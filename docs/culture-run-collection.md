## Garment rules

- Silhouettes: run tee, race tank, singlet. Mesh + split hem OK.
- **All-over print.** No embroidery patches. Hex C is flat print only.
- Gradient, brush, or marble is required. Solid dark + sticker graphic is the old look.
- Olive tactical stays on the lifting line.
- Singlet graphics must survive size S shoulders.

### Color notes

- **Blue Hour / Tide:** midnight `#0B1C3A` → tide `#1E6FB8` → cyan `#3EC6D9` → violet → magenta → coral `#F07A5A`
- **Bloom marble:** sakura `#E8A4B4` + rose `#C45B78` + cream
- **Dusk marble:** lilac `#C5B4D8` + dusk `#5C4A72` + lavender `#8B6FA8`
- **Heatmap:** black + orange `#FF6A00` + pink `#FF4D8D`
- **Home Soil:** indigo → magenta → gold sunrise
- **Bumi Strata:** soil `#4A3428` → terracotta `#B75B3A` → ochre `#C68D47` → sandstone `#D7B98E` + forest `#344235`
- **Moss Current:** river charcoal `#1A2420` + moss `#3F513B` + olive `#6E7B4A` + stone `#6A655A` + sand `#D8C6A2`
- **Sandstone Sumi:** espresso `#2C2420` + umber `#6D4234` + sandstone `#CCAA75` + smoke `#61554C` + cream `#E5D7BC`
- **Cacao Route:** cacao `#4C2E26` + clay `#A65B45` + dusty rose `#B27C73` + oatmeal `#E3D3B5` + sage `#74806B`
- **Watercolor capsule:** pigment edges should look transparent and layered—not paper texture, not an oil painting, and not a washed-out pastel.
