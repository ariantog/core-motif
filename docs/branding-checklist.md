# Corenation Men's Kanji Line — Staff Branding Checklist

**Use:** Print or duplicate per drop. Tick boxes as completed.  
**Owner channels:** @corenationmen (Instagram) | shopee.co.id/corenation | Offline dept store VM

---

## 1. Brand Voice & Visual Rules (Men's Kanji Line)

### Voice
- [ ] Copy tone is **confident and direct** — not luxury, not bro-toxic. Think Adidas training ads: disciplined, achievable, strong.
- [ ] Avoid ultra-premium language ("exclusive," "luxury," "elevated lifestyle"). Use: *performance, training, discipline, built to move.*
- [ ] Indonesian + English mix is OK for captions; kanji always includes romanization in first mention (e.g. *力 — chikara, power*).
- [ ] Men's kanji line **never** uses women's floral motifs (sakura, lavender) in same frame or SKU.

### Visual Rules
- [ ] Base colors: olive `#4A5240`, black, charcoal grey — max 3 structural colors per piece.
- [ ] Accent colors: cream `#D6CFB5`, gold `#D4AF37`, red `#C41E3A` — **one hero accent** per product face.
- [ ] Hexagonal **CN** logo (C frame + N inside) present on belts and primary apparel (waistband or hem).
- [ ] Kanji on apparel uses **black rectangular patch** (shorts/tees) or **gold/cream on dark overlay** (belts).
- [ ] Kanji stroke style: bold brush on belts; clean bold strokes on small patches (legibility at 3m).
- [ ] Wordmark: `CORENATION` or `CORE NATION` — all caps, wide sans-serif only.
- [ ] No more than **one hero kanji** per visible product panel.
- [ ] Mesh panels stay **kanji-free** (charcoal strip + black mesh at hem only).

---

## 2. Pre-Production Design Approval

### Design file review
- [ ] Kanji character verified with native speaker or trusted font source (correct stroke count, no accidental vulgar compounds).
- [ ] Romanization and English meaning documented on tech pack.
- [ ] Colors matched to palette swatches (olive, cream, gold, red — CMYK/ Pantone noted).
- [ ] Logo placement matches brand grid (belt: buckle → C logo → wordmark → kanji).
- [ ] Patch dimensions meet minimum spec (shorts patch ≥ 60×80mm; belt kanji 40–60mm tall).
- [ ] Print/embroidery method confirmed (subli, heat transfer, embroidery) with wash-test requirement (50+ cycles).
- [ ] Size run artwork checked — kanji scales correctly on S through XXL.
- [ ] Interior labels: composition, care, Corenation branding, **no** wrong gender line coding.

### Sample approval
- [ ] Pre-production sample photographed on neutral background (olive + black visible).
- [ ] Kanji legibility signed off at 3m distance (in-store / gym floor test photo).
- [ ] Color accuracy vs. approved swatch ( daylight + indoor gym lighting ).
- [ ] Stitching/patch adhesion pull test documented.
- [ ] Marketing lead + production lead **both** signed on sample approval form.

## 3. Photography & Social (@corenationmen)

### Shot list (per SKU or collection drop)
- [ ] Hero flat lay: front + back on olive or concrete grey surface.
- [ ] Detail macro: kanji patch, hexagon logo, mesh panel, waistband emboss.
- [ ] On-body: training context (gym floor, rack, belt worn) — authentic sweat/work optional, not overly styled.
- [ ] Belt: horizontal product shot matching mockup layout (hardware → logo → wordmark → kanji).
- [ ] Accessory in-use: gloves on bar, straps on deadlift, knee sleeve on squat (one action shot minimum).

### Instagram content
- [ ] Feed post: 4:5 or 1:1, kanji readable in thumbnail.
- [ ] Carousel: include meaning slide (*力 — Power*) for education + brand story.
- [ ] Reels: 15–30s, product in motion; on-screen text uses cream/white, not neon luxury fonts.
- [ ] Caption includes: kanji meaning, product name, Shopee link, `#CorenationMen` `#TrainWithPurpose`.
- [ ] Tag @corenationactive only when cross-promoting; primary tag @corenationmen for men's drops.
- [ ] No filters that shift olive to muddy brown or gold to yellow-green.

### Stories & engagement
- [ ] Poll or quiz: "Which kanji is your training vibe?" (link to collection doc internally).
- [ ] Sticker: Shopee link or "Shop Now" to shopee.co.id/corenation.
- [ ] Repost UGC only if kanji patch visible and on-brand (no competitor logos dominant).

## 4. Shopee Marketplace Listing Consistency

### Listing setup (per SKU)
- [ ] Product title format: `Corenation [Product Type] — [Kanji] [Meaning] | Men's Training`
  - Example: `Corenation Lifting Belt — 力 Power | Men's Training`
- [ ] Main image: white or light grey background, kanji centered and readable.
- [ ] Image 2–5: flat lay, detail, on-body, size chart.
- [ ] Variant names consistent: Olive/Black only unless drop expands colorways.
- [ ] Description block 1: brand promise (quality materials, accessible price vs. global brands).
- [ ] Description block 2: kanji meaning + romanization + collection name.
- [ ] Description block 3: fabric, fit, care, size guide link.
- [ ] Same hexagon logo thumbnail style across all men's kanji SKUs.
- [ ] Category tags: men's sportswear, gym, training accessories — aligned with Shopee taxonomy.
- [ ] Price positioning reviewed: preferable tier (not lowest discount bin, not luxury markup).

### Cross-listing hygiene
- [ ] Women's floral SKUs use separate listing templates — no kanji in women's hero images.
- [ ] Hijab line (@corenationhijab) not mixed in men's kanji bundle deals without clear labeling.
- [ ] Stock photos never reused across men's kanji and women's floral with only color swap.

## 5. Offline Department Store VM (Visual Merchandising)

### Men's Kanji Zone
- [ ] **Zone signage:** "CORENATION MEN — TRAIN WITH PURPOSE" + single hero kanji per season (e.g. 龍 or 力).
- [ ] Color story: olive, black, charcoal fixtures — red/gold accent props only (no pink/lilac in men's zone).
- [ ] Mannequins: athletic poses (squat, carry, belt display) — shorts patch facing customer traffic.
- [ ] Belt display: horizontal face-out at eye level, kanji readable from 2m.
- [ ] Accessory peg wall: grouped by collection (Strength / Discipline / Victory / Elements) with small kanji legend card.
- [ ] Price cards: same typography as Shopee titles; QR to Shopee store optional.

### Women's Floral Zone (contrast — do not blend)
- [ ] Sakura/lilac palette confined to women's fixtures — separate bay or opposite wall from men's kanji.
- [ ] No kanji mannequins in women's floral bay (and vice versa).
- [ ] Shared brand elements only: Corenation wordmark, quality messaging, Shopee QR at checkout endcap.

### Staff floor training
- [ ] Staff can explain hero kanji meaning in one sentence (cheat sheet at counter).
- [ ] Restock check: patches aligned, belts not tangled hiding kanji face.
- [ ] Weekly photo audit: men's zone vs. women's zone sent to marketing lead.
